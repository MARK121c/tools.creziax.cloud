# 🚀 Apex AI Sales Agency & CRM System (Web Tool)

هذه الأداة هي أداة المبيعات واستقطاب العملاء B2B المتكاملة عبر الويب:

- **الرابط المباشر:** يشتغل على السيرفر سحابياً على مسار الجذر `/`.
- **المكونات:** صائد عملاء يوتيوب (`/scraper`)، إدارة العملاء (`/crm`)، استوديو عروض الذكاء الاصطناعي (`/pitches`)، والاجتماعات والإحاطات (`/meetings`).
- **المعمارية:** Next.js 14 + SQLite + Prisma + Google Gemini Flash + Nodemailer SMTP.
- **التشغيل:** يتم تشغيلها وإدارتها تلقائياً عبر حاوية Docker على السيرفر.
