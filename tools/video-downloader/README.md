# 🎬 أداة تنزيل الفيديوهات ومقاطع يوتيوب بجودة فائقة واقتطاع الأجزاء

أداة متقدمة لتنزيل مقاطع الفيديو من **YouTube و TikTok و Instagram** بأعلى دقة ممكنة (4K, 1080p, 720p, أو استخراج الصوت MP3) مع إمكانية **تحديد واقتطاع أجزاء معينة فقط من الفيديو** بالثواني والدقائق.

---

## 🌟 أبرز المزايا:

1. **تنزيل بأعلى جودة:**
   - يوتيوب: دعم جودات 4K (2160p)، 1080p Full HD، 720p HD، 480p، أو صوت فقط MP3.
   - تيك توك: أفضل جودة أصلية بدون علامات مائية.
   - إنستقرام: دعم الريلز (Reels) والفيديوهات والمنشورات المتعددة (Carousels).

2. **اقتطاع وتنزيل أجزاء محددة (Time Segment Clipping):**
   - تحديد وقت البداية ووقت النهاية (`Start Time` و `End Time`).
   - تنزيل الجزء المطلوب فقط مباشرة دون الحاجة لتحميل الفيديو كاملاً، مما يوفر الوقت وسرعة الإنترنت.

3. **واجهة استخدام عصرية وخفيفة:**
   - واجهة ويب Dark Mode باللغة العربية.
   - شريط تقدم مباشر (Live Progress Bar) لمعرفة النسبة المئوية وسرعة التحميل.
   - معاينة الفيديو والصورة المصغرة والمدة والقناة قبل التحميل.

---

## 🚀 طريقة التشغيل السريع على Windows:

1. **التشغيل بنقرة واحدة:**
   - اضغط مرتين على ملف **`start.bat`**.
   - سيقوم تلقائياً بتثبيت الحزم (Express و UUID) وفتح المتصفح على:
     `http://localhost:3500`

2. **أو عبر سطر الأوامر:**
   ```bash
   cd tools/video-downloader
   npm install
   node server.js
   ```

---

## 📁 هيكلية ملفات الأداة:

```text
tools/video-downloader/
├── server.js          # خادم Express الخلفي للتعامل مع yt-dlp ومسارات التحميل
├── package.json       # تبعيات Node.js
├── start.bat          # سكربت التشغيل التلقائي لنظام ويندوز
├── yt-dlp.exe         # محرك yt-dlp المحدث لتنزيل الفيديو
└── static/            # واجهة المستخدم الأمامية
    ├── index.html     # صفحة الواجهة
    ├── style.css      # التنسيقات العصرية
    └── app.js         # معالجة الطلبات وشريط التقدم
```
